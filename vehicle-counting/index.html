LiDAR-Based Vehicle Counting & Remote Monitoring

Menghitung kendaraan di lapangan, dipantau dari mana saja.

Vehicle Counting menggunakan sensor LiDAR TF02-Pro untuk mendeteksi dan menghitung kendaraan di kondisi outdoor, lalu mengirim datanya lewat jaringan 4G LTE sehingga bisa dipantau dari jarak jauh tanpa akses internet kabel atau WiFi di lokasi.

Latar Belakang

Kenapa Vehicle Counting dibuat

Penghitungan kendaraan di lapangan membutuhkan sensor yang andal untuk kondisi outdoor, serta jalur komunikasi yang stabil untuk mengirim data ke sistem monitoring dari lokasi yang mungkin tidak memiliki akses internet kabel atau WiFi.

  • Deteksi kendaraan pakai sensor LiDAR
  • Dirancang tahan untuk kondisi outdoor/lapangan
  • Komunikasi data pakai RS485
  • Kirim data lewat 4G LTE, tanpa perlu WiFi lokasi

Arsitektur Sistem

Dari sensor LiDAR sampai sistem remote

Sensor LiDAR TF02-Pro mendeteksi kendaraan yang lewat, data diproses oleh ESP32-S3, dikomunikasikan lewat RS485, lalu dikirim ke sistem remote lewat 4G LTE.

TF02-Pro LiDAR → ESP32-S3 → RS485 → 4G LTE → Remote Monitoring System

TF02-Pro LiDAR

Mendeteksi keberadaan dan jarak kendaraan yang melintas.

ESP32-S3

Memproses data jarak dari LiDAR menjadi hasil penghitungan kendaraan.

RS485

Jalur komunikasi data yang stabil untuk kondisi lapangan.

4G LTE

Mengirim data ke sistem remote tanpa perlu jaringan WiFi lokal.
