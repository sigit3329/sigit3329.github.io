Latar Belakang

Kenapa project ini dibuat

Data sensor suhu mentah memiliki noise dan variasi bacaan, sehingga sulit dijadikan acuan yang stabil, terutama saat membandingkan performa antar sensor.

  • Membandingkan beberapa sensor suhu sekaligus
  • Mencatat data mentah (raw) untuk referensi
  • Menghaluskan sinyal dengan Kalman Filter
  • Data raw dan filtered bisa diekspor untuk analisis

Arsitektur Sistem

Dari sensor mentah sampai data yang stabil

Beberapa sensor suhu dibaca secara paralel lewat ESP32, dicatat sebagai data mentah, lalu diproses dengan Kalman Filter sebelum divisualisasikan.
