RFID & RF-Based Vehicle Security System

Dua jalur akses, satu status kunci yang selalu tersimpan.

Smart Motor Security menggabungkan RFID (PN532) dan RF 433 MHz untuk kontrol akses dan penguncian nirkabel, dengan status kunci manual yang tetap tersimpan di EEPROM meski perangkat mati atau restart.

Latar Belakang

Kenapa Smart Motor Security dibuat

Kunci konvensional pada kendaraan rentan terhadap duplikasi dan tidak memiliki kontrol akses maupun status kunci yang bisa dikonfigurasi secara elektronik.

  • Kontrol akses lewat RFID PN532
  • Penguncian nirkabel lewat RF 433 MHz
  • Status kunci tersimpan permanen di EEPROM
  • Tetap berfungsi meski perangkat restart

Arsitektur Sistem

Dari input akses sampai status kunci

Sistem menerima input dari RFID PN532 dan RF 433 MHz, memproses logika akses, lalu menyimpan status kunci secara persisten di EEPROM.

RFID PN532 / RF 433 MHz → Access Control Logic → EEPROM Persistent State → Embedded Security Control → Manual / Wireless Lock

RFID PN532

Membaca kartu/tag RFID sebagai salah satu jalur akses.

RF 433 MHz

Modul RF sebagai jalur kontrol nirkabel tambahan.

Access Control Logic

Menentukan keputusan buka/kunci dari kedua sumber input.

EEPROM Persistent State

Status kunci disimpan permanen, tetap ada meski listrik mati.

Embedded Security

Logika keamanan berjalan langsung di embedded controller.

Manual / Wireless Lock

Kunci dapat dikontrol manual maupun secara nirkabel.
