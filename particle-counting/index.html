Latar Belakang

Kenapa Particle Counting dibuat

Menghitung dan memantau jumlah partikel secara manual tidak praktis untuk kebutuhan monitoring yang berkelanjutan, dan membutuhkan pemrosesan sinyal yang konsisten agar hasil counting bisa diandalkan.

  • Deteksi partikel otomatis lewat sensor
  • Counting diproses langsung di embedded controller
  • Data dicatat (logging) untuk ditelusuri
  • Bisa dipantau berkelanjutan, bukan sesaat

Arsitektur Sistem

Dari sensing sampai monitoring

Sistem melakukan sensing dan akuisisi data partikel, memproses hasil deteksi di embedded controller, lalu mengirim dan mencatat datanya.

Particle Sensing

Sensor mendeteksi keberadaan partikel pada jalur pengukuran.

Data Acquisition

Hasil pembacaan sensor diakuisisi untuk diproses lebih lanjut.

Embedded Processing

Data diproses di embedded controller untuk menghasilkan angka counting.

Detection & Counting

Logika deteksi menentukan dan menghitung partikel yang terbaca.

Communication

Hasil counting dikirim melalui jalur komunikasi ke sistem monitoring.

Monitoring & Data Logging

Data dipantau dan dicatat untuk keperluan analisis lebih lanjut.
