Kontrol pengisian galon otomatis, berbasis waktu dan dipantau lewat kualitas air.

PurityFlow mengatur proses pengisian air galon di depot secara otomatis: durasi pengisian konsisten, kualitas air dipantau lewat sensor TDS secara real-time, dan jumlah galon yang sudah terisi tercatat otomatis meski listrik sempat mati.

Tujuan Sistem

Kenapa PurityFlow dibuat

Operator depot air butuh alat yang konsisten dan tidak ribet dioperasikan, bukan sekadar timer manual.

  • Mengotomatisasi proses pengisian air galon
  • Menjaga durasi pengisian tetap konsisten
  • Mencegah overfill dan air tumpah
  • Menampilkan kualitas air secara real-time
  • Mencatat jumlah galon yang sudah diisi
  • Kontrol yang sederhana untuk operator depot

Arsitektur Sistem

Susunan hardware

Sistem bekerja berdasarkan waktu, bukan volume, dengan LCD 20x4 sebagai pusat tampilan dan rotary encoder sebagai kontrol utama.

Microcontroller

ESP32 sebagai pusat kontrol seluruh sistem.

Sensor

Sensor TDS membaca kualitas air dalam satuan ppm.

Output

Relay untuk buka tutup aliran, buzzer, LED indikator, dan LCD 20x4.

Input

Rotary encoder untuk navigasi, tombol start, dan tombol reset.

Network

WiFi untuk OTA update firmware dan pengiriman data ke server.

Mode Operasi

Tiga mode kerja terpisah

Dipisah supaya sistem tetap stabil, terutama saat proses pengisian sedang berjalan.

Monitoring

Menampilkan status sistem, nilai TDS, kualitas air, dan total galon terisi dibanding target.

Mengisi

Menjalankan countdown timer dan relay. WiFi dimatikan sementara supaya tidak ada delay selama proses berjalan.

Setting

Atur durasi pengisian dan target galon. Putar encoder untuk ubah nilai, tahan 3 detik untuk simpan.

Simulasi

Coba dashboard-nya

Ini simulasi ringan di browser yang meniru tampilan LCD dan alur kerja controller aslinya. Data tersimpan di perangkat kamu sendiri, seperti EEPROM pada alat fisiknya.

    Keamanan

    Proteksi operasional

    • Pengisian berbasis timer presisi untuk cegah overfill
    • WiFi nonaktif otomatis selama proses pengisian
    • Start terkunci jika target galon sudah tercapai
    • Reset counter hanya lewat tombol tahan beberapa detik

    Penyimpanan & Data

    EEPROM dan pengiriman ke server

    Total galon, setting durasi, dan target maksimum disimpan di EEPROM sehingga tetap ada meski listrik mati. Saat online, ESP32 mengirim TDS dan total galon ke server dengan format berikut.

    /PurityFlow/public/values/{tds}/{total}
