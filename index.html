Tentang Saya

Tentang Saya

IoT Product & Systems Engineer

Sigit Berkarya adalah nama personal brand yang saya pakai untuk seluruh proyek, konten edukasi, dan portofolio ini, milik saya, Muhammad Sigit Nugroho.

Saya adalah IoT Product & Systems Engineer yang berfokus pada pengembangan sistem terintegrasi dari hardware, embedded systems, connectivity, data processing, hingga backend dan web dashboard.

Saya memiliki pengalaman membangun dan mengembangkan solusi berbasis ESP32 dan STM32, mengintegrasikan berbagai sensor dan aktuator, merancang komunikasi data, melakukan optimasi data sensor, serta menghubungkan perangkat dengan platform monitoring dan layanan cloud.

Pendekatan saya berorientasi pada problem solving dan product development. Saya tidak hanya berfokus pada membuat prototype bekerja, tetapi juga mempertimbangkan reliability, efisiensi biaya, kebutuhan pengguna, maintainability, scalability, dan kesiapan implementasi di dunia nyata.

Selain engineering, saya aktif dalam robotics education dan technical mentoring, khususnya dalam pengembangan materi IoT, Robotika, Embedded Systems, dan OSN Informatika berbasis praktik dan problem solving.

Keahlian Utama

Area kerja yang saya kuasai, dari hardware sampai dashboard.

01

Embedded & IoT Systems Development

Pengembangan perangkat berbasis ESP32 dan STM32 dari prototipe hingga implementasi lapangan, termasuk integrasi sensor dan aktuator, kalibrasi, komunikasi data, persistent configuration, serta OTA update.

02

End-to-End System Integration

Perancangan sistem terintegrasi dari edge device hingga cloud dan dashboard, mencakup komunikasi perangkat, real-time data flow, REST API, WebSocket, serta sistem notifikasi menggunakan Telegram dan berbagai layanan lainnya.

03

Web Dashboard & Backend Development

Pengembangan platform monitoring dan dashboard menggunakan Laravel dan Next.js, termasuk REST API, WebSocket, authentication, manajemen data perangkat, serta integrasi antara perangkat IoT dan aplikasi web.

04

Data Processing & Sensor Optimization

Pengolahan dan optimasi data sensor menggunakan Kalman Filter, signal smoothing, filtering, calibration, dan data logging untuk meningkatkan stabilitas, konsistensi, dan kualitas data.

05

Hardware & Software Co-Design

Perancangan sistem dengan mempertimbangkan keterkaitan antara hardware, firmware, komunikasi, power system, backend, dan user interface, sehingga keseluruhan sistem dapat bekerja secara optimal sebagai satu kesatuan.

06

Product Development & Engineering Decision Making

Pengembangan produk IoT dengan mempertimbangkan technical feasibility, reliability, BOM, cost efficiency, component availability, user requirements, maintainability, dan production readiness.

07

Rapid Prototyping & Iterative Development

Pengembangan solusi menggunakan pendekatan build, test, refine untuk memvalidasi konsep, menemukan masalah teknis lebih awal, dan menyesuaikan sistem dengan kebutuhan nyata di lapangan.

08

Robotics & Automation Systems

Perancangan sistem robotika dan otomasi yang menggabungkan sensor, aktuator, embedded controller, komunikasi, dan algoritma kontrol untuk kebutuhan edukasi maupun aplikasi nyata.

09

Technical Education & Mentoring

Penyusunan materi, kurikulum, modul praktikum, dan pelatihan Robotika, IoT, Embedded Systems, serta OSN Informatika dengan pendekatan project-based learning, praktik langsung, logika, dan problem solving.

Cara Saya Bekerja

Mengubah kebutuhan teknis menjadi sistem yang benar-benar bekerja di lapangan.

Problem & Requirement → System Architecture → Hardware & Sensor Selection → Embedded Firmware → Connectivity & Communication → Data Processing → Backend & API → Dashboard & User Interface → Testing & Optimization → Deployment

Dengan pendekatan tersebut, saya dapat mengembangkan solusi IoT secara end-to-end, baik untuk kebutuhan prototyping, monitoring, automation, robotics, maupun pengembangan produk.
